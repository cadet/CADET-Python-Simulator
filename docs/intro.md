# CADET-Python-Simulator

A Python prototype for simulating systems of unit operations in chromatography and filtration.
This is a research and prototyping tool — not a production alternative to CADET-Core — intended for
exploring new physical models, numerical approaches, and software abstractions.

## What this is for

- Testing new unit operation models (filtration, chromatography columns, reactors)
- Exploring extensions to CADET's internal structure (pressure coupling, solvent accounting)
- Learning and experimenting with DAE-based simulation
- Playground for isotherm models, coupling modes, and spatial discretizations

## Structure of this documentation

**Concepts** — explains the key abstractions and why they exist. Start here if you want to
understand the design before using the API.

**API Reference** — describes each module and class in detail.

**Examples** — worked examples showing how the pieces fit together.
